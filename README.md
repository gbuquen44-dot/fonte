# Fonte

Appli personnelle de suivi powerbuilding, en page web pour iPhone. Les données ne sont pas ici : elles vivent dans un dépôt privé, atteint avec un jeton gardé sur le téléphone.

- `npm run dev` lance l'appli avec des données d'exemple.
- `npm test` lance les tests.
- `npm run build` construit le site dans `dist`.
- `scripts/build-shortcut.py` construit et signe le Raccourci Santé.
